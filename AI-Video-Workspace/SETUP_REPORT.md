## 项目选择和安全判断

首选候选：[jianying-ai-mcp](https://github.com/Xanthus-Sanslab/jianying-ai-mcp)，核查提交 `ae14f5356ae1499a247937077af550a34d580beb`、版本 0.3.0。作者测试基线为剪映 10.0.5.13816；本机 8.9.0.13361 是否兼容为 **UNKNOWN**，不能仅因版本不同断言一定不兼容。官方仓库整体许可证未明确，子组件许可证不能自动推广到整个仓库。

固定提交的 `src/jianying_ai_mcp/draft_ops.py` 显示：`dry_run` 仍创建草稿根目录和暂存草稿，最终递归删除暂存；发布流程先检查目标不存在再复制，异常时如果目标存在且不含锁文件会递归删除。检查、复制、清理之间存在竞态，不能证明被清理目录一定属于本次操作，因此不允许对真实草稿根使用该发布流程。仓库还提供调用剪映 DLL 读取加密草稿的可选路径，本轮未启用或调用。

备选 [aoguai/pyJianYingDraft](https://github.com/aoguai/pyJianYingDraft) 核查提交 `69cee12ae3f7442416df16acdf368ae574764811`，Apache-2.0；其加密草稿参考实现使用本机 DLL，作者列出的测试范围是 10.3.0–10.6.5。按本任务安全门禁不调用 DLL 或处理加密草稿。现有证据不足以推定其在本机 8.9 的草稿可用。

音效扩展 [jedliuai/jianying-mcp](https://github.com/jedliuai/jianying-mcp) 核查提交 `38a293468ba6a09229551a3b0fe67fc5cf81db92`，仅调研；它涉及已有草稿、DLL 及共享索引写入，未安装、未执行。仓库未见明确整体许可证。

## 安装、配置与限制

- 独立工作区：`<工作区>\AI-Video-Workspace`；独立 Python 3.12.4 环境在 `.venv`，以 `--without-pip` 创建；未安装 MCP、pyJianYingDraft 或其他依赖。
- GitHub、PyPI 的命令行 DNS 查询受限，当前环境和已检查 pip 构建缓存中缺少依赖，无法完成可靠安装。未执行一键安装或下载不明二进制。
- 未创建或修改 Codex MCP/Skill 配置，故没有配置备份，也无需恢复配置；当前会话未发现剪映 MCP 工具。未来安装需在独立环境验证实际发现与握手，不可将配置文件存在当成接入成功。
- 设置中指向的草稿根目录在当前会话允许的写入范围之外；即使用户授权本次任务，当前进程仍不能直接写入该位置。尚无测试草稿路径，未进入用户手动验收。
- 移除集成：本轮未注册 MCP 或 Skill，关闭集成无需任何配置操作；若未来另行安装，再以当时生成的备份和恢复记录为准。独立虚拟环境和合成测试文件保留，不自动删除。
