# Phase 4 主规划：本地 AI Rough Cut

本文件定义 V1 目标及门禁，并不表示各阶段已经通过。Phase 4A 的真实完成情况以 [验收记录](evidence/PHASE4A-REPORT.md) 为准；未经独立审查及用户实际 Studio 验收，不得将生成的文件称为可正常编辑的成片工程。

## 目标和分工

面向自然、注重叙事、偶尔幽默的科技及生活 VLOG，先以明确授权的材料形成可追溯、可人工审核的剪辑计划，再生成可在本地 OpenFilm 中继续编辑的新工程；项目风格遵循 [STYLE.md](../STYLE.md)，具体任务指令优先。

| 组件 | 职责 | 边界 |
| --- | --- | --- |
| Codex | 理解经授权的素材、规划叙事及建议、呈现证据 | 不擅自处理个人素材；不以识别结果代替人工判断。 |
| ClipPlan | 记录来源、源时间到成片时间映射、审核状态和修订历史 | 版本化记录不代表任意撤销机制已实现；待审核不能被当成已批准。 |
| OpenFilm 0.2.7 | 目标工程格式、时间线与预览；由用户人工确认编辑性 | 本阶段只创建新工程，不修改个人工程，不把解析通过当作 Studio 打开通过。 |
| OpenFilm 自带 FFmpeg / FFprobe | 本地素材元数据和必要媒体验证 | 不原地覆盖、删除或重写源素材；不将纯 FFmpeg 产物冒充 OpenFilm 工程。 |
| faster-whisper | 本地内容理解的已有工具 | 沿用既有环境，本阶段不修改 ASR 内核；识别误差、时间边界和原生网络隔离限制继续保留。 |
| 剪映 | 后续按需字幕及人工精修 | 本阶段不修改剪映草稿、不接入剪映 MCP；是否支持导入另行验证。 |

## V1 范围与阶段顺序

1. **Phase 4A：基础契约与新工程。** 定义可审核 ClipPlan、源文件和源时间绑定、时间线校验、OpenFilm 生成子集、隔离合成素材测试。只输出新工程，不做自动语义删剪、云服务、字幕生成或正式素材处理。人工在 Studio 检查仍是独立门禁。
2. **后续候选：受保护的素材分析和故事决策。** 仅在用户另行指定、授权及前置门禁通过后，研究口播、字幕、停顿、B-roll 和叙事证据映射；不得把静音检测视为安全删减或语音保护证明。
3. **后续候选：用户审核和修订闭环。** 按用户认可的交互实现建议接受、拒绝和撤销，保留版本历史；确定引用、状态及音画规则后再允许针对真实素材生成新的可编辑工程。
4. **后续候选：交接与质量检查。** 根据实际版本验证字幕/精修交接、媒体路径、构图、人声和背景音乐完整播放及导出；不承诺剪映可直接打开 OpenFilm 工程。

以上后续项是方向而非已批准开发范围；本阶段结束后停止，不自动进入 Phase 4B / 4C / 4D 或处理正式视频。

## 时间、状态与安全契约

- 源时间、时间线时间均以秒表示、分开存储；片段区间采用左闭右开 `[start,end)`，源区间必须在媒体已知时长内。输出精度取决于 OpenFilm 实际协议；任何量化造成零长度、边界越界或同轨重叠须拒绝，不悄悄改变语音。
- 同一轨道片段不允许非法重叠，不同轨叠加仅在明确角色和音频处理规则下允许；视频自带声音需单独处理，B-roll 不得意外覆盖、静音或替换口播。对未验证的叠层和声音组合应拒绝或标为 NOT_RUN。
- 审核状态至少区分待审、接受和拒绝；只允许明确通过审核的最终片段进入项目，审核状态变化有可追溯修订。历史字段、哈希及人工标注不能证明语音内容完整，任何人物/笑声/自然停顿都需要人工逐项核实。
- 每份计划记录源媒体 ID、受限路径映射、SHA-256、时长和引用证据。读取前后校验哈希；路径必须位于授权根目录，拒绝绝对路径或目录穿越造成的越界。必须显式提供已存在的 `allowed_output_root`，工程只能独占创建在其直接新子目录，且源根与输出根不能相同或互相嵌套；不覆盖既有工程或源文件，不清理失败时的个人文件。
- 输入、计划、素材和生成文件默认本地；不上传私人音视频、模型、令牌或私人路径，不调用付费服务，不修改操作系统安全策略。公开仓库只提交必要代码、合成测试生成逻辑与脱敏报告。

## 验收与既有阶段

Phase 4A 的结构/逻辑测试、源哈希和安全失败需逐项记录，真实 OpenFilm Studio 的加载、轨道、画面、人声及可编辑性必须由用户人工验证，尚无确认时为 WAITING_USER_CHECK；详见 [验收标准](PHASE4A-ACCEPTANCE.md)。

Phase 2C 的标题保存重开和完整试听继续 WAITING_USER_CHECK；用户接受当前 60 fps 用途不等于 30 fps 已测试。Phase 3B / 3C 的真实模型与单条合成中文冒烟证据保留，但真人质量和原生进程完整离线隔离仍未验证。本阶段不将上述项目改写为 PASS。
