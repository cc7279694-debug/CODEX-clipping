# 个人 AI 视频剪辑工作站

这是一个面向自然语言协作的本地工作区，用于整理视频、制定剪辑方案并在工具可用时执行和检查剪辑。风格偏好见 [STYLE.md](../STYLE.md)。本次仅进行环境搭建与合成素材测试，不处理正式拍摄素材。

## 使用方式

之后开始正式项目时，可在本工作区向 Codex 描述目标，例如：

> 请按 STYLE.md 帮我制作一条 9:16 的科技 VLOG。先只读扫描我指定的素材，给我故事结构、候选剪辑点、保留的自然停顿和 B-roll 建议，再制作可修改的剪辑方案与预览；不要修改原素材，也不要上传。

请明确素材路径、视频主题、大致时长、目标平台及想保留的内容。Codex 应先检查工具和依赖是否可用，再根据实际结果说明哪些步骤可以完成；本说明不是自动执行程序。

## 每条视频的建议流程

1. **规划**：确定受众、故事重点、画幅与大致时长；只读盘点授权素材，记录时长、画面、音频和候选镜头。
2. **内容与剪辑方案**：结合素材制定故事结构、镜头顺序、时间线和 B-roll 清单；缺少的镜头标注待补拍，不能凭空认定素材内容。
3. **粗剪与字幕**：提出可缩短的冗长静音，保留自然呼吸与笑点；根据可用的本地语音识别与翻译能力生成草稿，再人工校对中英文、断句和时间。没有安装模型时，这两项不能宣称可用。
4. **精剪与声音**：按需要裁剪、缩放、基础调色、添加 B-roll，并平衡人声与背景音乐。先出可修改的方案或项目，再生成独立预览。
5. **导出与检查**：按平台输出 9:16 视频，检查编码、分辨率、时长、画面、字幕、人声、音乐、剪辑点和开头结尾；机器检查不代替完整观看与试听。

## 安全约定

- 指定的用户原视频只读，不覆盖、不移动、不删除；所有生成文件使用独立位置和新名称，不覆盖已有成果。
- 不上传私人视频、音频、字幕或分析结果到云端；如有工具默认使用云服务，需明确关闭，无法确认时停止该步骤。
- 不擅自购买、订阅、改系统配置或安装全局组件；项目使用独立目录，优先复用已有软件。
- 保存剪辑决策、字幕、时间线和渲染参数等可修改文件。能否直接导入特定剪辑软件取决于所使用的项目格式，需单独验证。
- 音乐和素材应确认使用权；真实素材的识别、翻译和审美效果都需要人工复核。

## 安装与测试状态

当前已可复用 OpenFilm 自带的 FFmpeg，并已运行合成视频测试；OpenFilm 的 Studio、完整剪辑与导出仍需验证。详细记录见 [STATUS.md](../STATUS.md)。

以工作区实际的安装与验收记录为准。两个上游项目、FFmpeg/FFprobe、中文转录及英文翻译的安装和实际效果需要逐项验证；合成素材测试通过也不代表所有真实手机素材可用。未完成的功能应标注未验证或未实现。
