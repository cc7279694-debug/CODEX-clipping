# Phase 3A：中文口播智能粗剪技术方案

状态：**READY_FOR_REVIEW（仅方案）**。本轮没有安装语音识别依赖、下载模型、开发粗剪程序或处理真人口播；识别准确率、时间戳、静音识别、误删率、耗时及资源占用均为 **NOT_RUN**。Phase 2C 的人工标题保存重开和完整试听尚待确认；这不影响评审本方案，也不代表已批准后续实施。

## 目标与范围

后续在 Windows 本机读取一段明确授权的中文口播，输出元数据、带源时间戳的中文字幕、静音检测结果、建议删剪片段和供人审核的剪辑决策 JSON。用户可以逐条接受、拒绝或撤销建议，之后再决定是否另行授权实际剪切。

第一版只生成**建议**，不自动删除音视频、不制作成片、不覆盖原素材，不修改现有 OpenFilm 工程或剪映草稿。时间信息始终以原视频为基准，原文件只读；所有生成文件保存在独立项目目录中。未经授权不上传音频、视频或转录结果，也不调用云服务或付费 API。

## 拟选技术路线

首选**评估 faster-whisper 多语言 `small`、CPU `int8`**，以单进程和受控线程数运行；在内存、处理时间或初次测试不合适时，将多语言 `base` 作为资源较低的候选。不能使用仅英文的 `.en` 模型来验证中文。两个模型的中文识别效果都必须由本机测试决定，不能预先认定 small 或 base 达到可用质量。

官方模型仓库当前列示 small 模型目录约 **486 MB**、base 约 **148 MB**；大小随版本及计量方式变化，另外还需空间保存 Python 依赖、缓存、临时文件和测试记录。上游公布的其他机器基准不能代表这台电脑的速度或内存。当前可用内存偏少，应先测短样本和峰值；若资源不足，明确记录并停止，不强行并发或占满内存。

GPU 不作为首轮默认方案。faster-whisper 的 GPU 路径涉及 CUDA 和 cuDNN；本机 GTX 1050 Ti 与所选版本组合是否可用尚未验证，4 GiB 显存不保证成功。本阶段不安装或改动系统 CUDA、驱动及安全配置。可将支持 Windows CPU 的 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 作为后续备选；其模型格式、依赖、时间戳和性能需要独立验证，不能把上游资源估计当成本机结果。

### 离线与依赖门禁

1. 后续实施前先确认可用网络和可信来源，在独立目录准备并核验指定版本的 faster-whisper、CTranslate2 及其依赖，锁定版本与哈希；不执行未知的一键远程安装脚本，不安装重复 Skill。现有网络限制未解除时标记 BLOCKED。
2. 模型**首次获取**与后续**本地推理**分开记录：下载的是公开模型，不发送用户素材；推理显式指向完整的本地模型目录，不允许静默切换到云识别或上传音频。
3. 对固定模型版本核验清单与哈希，包括 `model.bin`、`config.json`、`tokenizer.json` 和该版本实际要求的其他文件。不能只依赖 `local_files_only=True` 断言完全离线：缺失 tokenizer 等文件时，上游代码可能走其他获取路径。缺少必要文件时应先失败；在可控断网条件下实际验证完整及缺失文件两种行为。
4. 隔离环境、模型获取、运行日志及退出状态都要保留证据；依赖、模型许可和版本可核验后才运行。ASR、字幕和静音检测不因依赖安装成功而自动视为 PASS。

## 处理流程与输出

1. **只读扫描**：FFprobe 检查授权视频的时长、分辨率、帧率和音轨；计算源文件 SHA-256。无音轨、文件异常或权限不足时停止相关步骤并报告。
2. **离线转写**：本地生成中文转写和带源时间的句段。识别出的文字、语种和时间戳属于待审结果；低音量、噪声或音乐可能造成漏识别或幻觉。
3. **字幕**：从句段生成 SRT，确保时间递增、结束不早于开始且不越过源时长。句级时间戳不是已验证的逐字对齐；用户可校正文案和时间。
4. **静音候选**：FFmpeg `silencedetect` 只提供符合阈值的低电平区间。阈值、最短时长、合并规则及讲话前后保护时长均为 **PROPOSED**，需用样本调整；低音量讲话、呼吸、笑声、幽默停顿和背景音乐不能直接判作无意义。
5. **删除建议与审核**：结合字幕与静音候选生成建议清单，保守保留语句前后边界；有低声、笑声、重叠语音、时间戳不确定或靠近语音的区域标记风险或不提出删除建议。默认全部为“待审核”，绝不直接执行删剪。
6. **撤销与后续编辑**：接受、拒绝和撤销只改变决策记录；保留原始建议和审核修订。只有用户另行授权实际剪切，才生成新文件或新工程，不回写或覆盖源视频。

建议生成独立的 `metadata.json`、`transcript.srt`、`silence-candidates.json` 和 `edit-decisions.json`。出现任一阶段失败，已完成结果可保留并标记状态；不得伪造缺失的转写或直接把静音结果当作可安全删除区间。

## 决策 JSON 的最小结构

以下是设计字段，不是已实现格式：

```json
{
  "schema_version": 1,
  "source": {"relative_path": "media/input.mp4", "sha256": "<source-hash>", "duration_seconds": 120.0},
  "time_base": "source_seconds",
  "asr": {"engine": "faster-whisper", "version": "<locked-version>", "model": "small", "model_hash": "<model-hash>", "language": "zh"},
  "transcript_segments": [{"id": "s1", "start": 1.2, "end": 3.1, "text": "示例句子"}],
  "suggestions": [{"id": "cut1", "start": 8.0, "end": 9.1, "reason": "long_silence", "risk": "review_required", "status": "pending"}],
  "review_history": []
}
```

建议保留引擎、依赖及模型版本/哈希、语言与参数、源字幕、候选 ID、源开始/结束时间、原因、风险提示和审核状态；如引擎提供置信信息，保留其来源与含义，不能把它当作人声安全保证。审阅历史使用追加记录或可追溯版本保存状态变更。校验时间范围、排序、重复 ID 和候选区间重叠；对冲突区间要求人工处理，不猜测合并或覆盖。拒绝、撤销均不改源文件。

## 测试与拟定验收标准

下表阈值均为 **PROPOSED（拟定）**，不是现有通过结果、通用质量保证或已冻结标准；实施前应确认测量口径。没有中文语音或没有模型时，对应识别、时间戳、误删和性能均为 **NOT_RUN**，不得使用纯音来冒充中文识别测试。

| 项目 | 测法与拟定标准 |
| --- | --- |
| 样本 | 中文 TTS 可单独用于工程冒烟，但不能代替真人质量评估；至少需要 1 段明确授权、可丢弃的中文真人口播作初步可行性检查。正式判断建议 5–10 段，覆盖自然停顿、呼吸、笑声、轻声、轻噪声和少量英文术语，包含较长样本。小样本结果不得外推。 |
| 参考标注 | 独立人工逐字转写，并标注每句话及笑声等应保留内容的源起止时间；记录规范化规则、无法辨认内容和标注者。 |
| 中文识别 | 在事先确定文字规范化规则后，计算字符错误率 CER =（替换＋删除＋插入）/ 参考字符数。拟定清晰短样本 CER ≤ 15%；逐段报告并保留原文，不能仅给平均分。 |
| 字幕时间 | 报告句子可匹配覆盖率，以及开始和结束边界绝对误差的中位数、P95；拟定中位数 ≤ 0.3 秒、P95 ≤ 1 秒。未匹配的句子单列，不计为零误差；不宣称逐字精度。 |
| 静音 | 与人工标注区间逐段比对，分别列出误报、漏报、边界偏差和精确率／召回率；明确检测阈值和样本边界。背景音乐、噪声和自然停顿分别报告。 |
| 误删安全 | 删除候选若与人工标注讲话或笑声有任何重叠，记录次数和重叠秒数；拟定该样本安全门禁为 **0 条重叠候选**。没有人工作真值时，误删结果为 NOT_RUN。即使通过也必须人工审核，第一版不自动删除。 |
| 资源与耗时 | 分段记录源时长、模型首次获取/加载时间、转写及端到端时间、实时倍率 RTF（处理秒数 ÷ 音频秒数）、CPU、峰值 RAM/显存和磁盘空间；注明采样方法、引擎、版本及机器状态。 |
| 文件与离线 | 核对源文件前后哈希一致、输出目录独立、缺失模型失败、断网运行及无云回退；检查 SRT/JSON 均使用源时间且可追溯、撤销不改原文件。 |

不以一次合成样本或少量人工样本宣布“中文识别准确”或“永不误删”。遇到误删、模型联网、资源不足、时间轴不一致或结果不完整时，停止受影响步骤并记录事实，保留已有证据。

## 分阶段准入

1. **当前：方案审查。** 本文和依赖清单可供审查；不声称任何识别测试通过。
2. **环境准备准入。** 明确允许的下载渠道、固定模型和依赖版本、独立目录、磁盘与内存余量；完成来源及许可检查并验证离线行为。网络或资源不满足时 BLOCKED。
3. **定向验证准入。** 使用自制中文语音进行工程冒烟，再以明确授权的可丢弃真人样本、独立人工标注和冻结评测口径评估；结果按 PASS / FAIL / NOT_RUN 如实记录。
4. **产品使用准入。** 仅在样本质量、安全和性能结果经独立审核后，讨论扩大样本或执行真实剪切；用户须另行授权正式素材和实际输出。
