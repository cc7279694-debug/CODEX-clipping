## 环境和依赖准备

Python 3.12.4；本轮创建独立的 `AI-Video-Workspace/phase3b/.venv`，采用 `--without-pip`，解释器隔离验证通过。没有安装 pip、faster-whisper、CTranslate2、CUDA 或其他系统组件。复用 OpenFilm 附带的 FFmpeg / FFprobe 9.0.2。

检查时可用内存约 3.16 GiB，工作卷可用空间约 33.26 GiB；这是动态读数，不是推理容量保证。首轮候选为多语言 **base、CPU int8、单进程、2 个 CPU 线程**，尚未用模型验证速度或质量。可用内存不足时不启用 GPU 或强行并发。

官方 PyPI 的 faster-whisper 元数据地址与 Hugging Face 的 Systran base 模型 API 各做一次 5 秒请求，均超时；随后停止，没有换镜像、改网络路径或下载未知程序。准备记录位于本地 `AI-Video-Workspace/phase3b/dependency-evidence.json`。

因此本轮**没有实际安装版本、已解析依赖 lock、wheel 哈希、模型 revision 或模型文件哈希**，这些值保持未取得；官方源码版本或测试假值不能充当实际依赖锁定结果。后续必须先从官方来源获取固定版本的包及完整依赖和模型，核对许可、revision 与文件哈希，再验证真实加载。

## 已实现行为及边界

实现位于 `src/codex_clipping/`，提供 `analyze`、`check-model`、`propose` 和 `review` 命令；不提供实际剪切命令。

1. 使用本机 FFprobe 读取明确指定的测试媒体，提取本地分析 WAV，并用 FFmpeg 输出静音候选。源文件处理前后检查 SHA-256，输出使用新目录和独占写入，禁止覆盖。
2. ASR 适配器要求本地模型清单及关键文件在导入和初始化之前通过完整性校验；缺失、篡改、未锁定 revision 或版本不符时失败。显式使用 CPU int8、本地模型路径和有限线程；不设置云端回退。
3. `local_files_only=True` 不是唯一离线保证：预检覆盖 tokenizer 等关键文件；Python socket guard 与离线环境变量为额外防护。其单元测试不证明 C/C++ 原生依赖完全断网，实际离线推理仍未验证。
4. SRT 保留源时间坐标，校验时间顺序、范围和中文文本，不猜测缺失转录。当前仅支持已知零起点媒体；非零或未知音视频起点受控 BLOCKED，不推测偏移。提取音频时保留时间同步。
5. 静音只是低电平候选。默认语音保护证据不完整时，不产生可接受的删除建议；不能将 ASR 未识别到文字解释为没有低声讲话、笑声或叙事停顿。
6. 人工完成语音、笑声及自然停顿保护标注并绑定源哈希后，`propose` 可以产生默认 `pending` 建议。`review` 的接受、拒绝和撤销只生成新的 JSON，保留追加历史，始终不执行音视频剪切。JSON 字段及人工声明没有签名认证，不能作为不可伪造的 ASR 来源证明。

## 实际流程输出与资源范围

在本地 `AI-Video-Workspace/phase3b/smoke/pipeline-blocked-01/` 中，用明确标识的纯音静音素材运行分析流程。结果是 **BLOCKED**：元数据读取和静音候选检测通过；模型缺失使 ASR 阶段 BLOCKED，字幕阶段 NOT_RUN。写出 `metadata.json`、`silence-candidates.json`、`edit-decisions.json`、空的 `transcript.srt` 和分析 WAV。空字幕及空建议的序列化成功不是中文识别或建议可用性通过。

该无模型阻塞流程的耗时约 3.771 秒，Python CPU 时间约 0.125 秒，当前 Python 进程生命周期峰值工作集为 25,341,952 字节。此统计**不含 FFmpeg 子进程**，也不是 ASR 模型推理基准。真实 ASR 的 CPU、RAM 峰值和耗时均为 NOT_RUN。

开发中修正了测试临时目录在当前环境不可写、Windows 日志解码，以及非零音轨起点和异常保护标注的受控失败问题；相关失败与修复记录没有被当作 ASR 通过。最终代码检查命令为 `python -m unittest discover -s tests -v`（进程内设置 `PYTHONPATH=src`），本次记录为 41 项通过。
