# Phase 3B implementation

依据：已审查的 `docs/PHASE3A-PLAN.md`。本轮实现分析、字幕和可撤销审核，不执行剪切。

1. 在独立环境核查官方依赖和模型；失败记录 BLOCKED，不使用镜像。实际版本和模型 revision/hash 未取得前不写假 lock。
2. 实现本地模型 manifest 校验、CPU int8 单进程转写适配器；关键文件缺失或 hash/version 不符时在导入模型前失败。模型使用本地路径，禁云回退。
3. 实现 FFprobe/FFmpeg 本地文件适配与新建输出目录流程，源文件前后 SHA-256 校验、源时间不变、测量耗时和自身进程峰值工作集。
4. 纯逻辑模块生成 SRT、保守建议与接受/拒绝/撤销历史。先测试缺失模型、无效时间、覆盖拒绝、源 hash 不符和审核状态回放。
5. 在无模型时只验证元数据、已知静音和审核逻辑，模型测试与真人质量保持 NOT_RUN。正常 Windows 无可调用中文 TTS 时不伪造中文语音。
6. 复核全部新测试、公开内容和历史文档，提交源码及脱敏报告；不上传素材、模型、依赖或机器日志。

独立文件职责：`asr.py` 负责模型预检和实际适配，`media.py` 负责元数据和静音，`pipeline.py` 负责无覆盖分析流程，`decisions.py` 与 `subtitles.py` 负责纯逻辑，`cli.py` 提供命令。安全测试与纯逻辑测试使用标准库；其结果不等于真实 ASR 通过。
